# Tic Tac Toe

A simple two-player Tic Tac Toe game built with HTML, CSS, and vanilla JavaScript.

## Features
- Classic 3 × 3 board for two players (X and O)
- Detects wins across rows, columns, and diagonals
- Detects a draw when all cells are filled with no winner
- Stops accepting moves after a win or draw
- Restarts the board from the result dialog

## Run locally
1. Clone this repository: **git clone https://github.com/Vikram2005-byte/tictac-game.git**
2. Open the repository folder.
3. Open **index.html** in a modern browser. No build step is required.

You can also serve the folder with **python -m http.server 8000** and open **http://localhost:8000**.

## Project files
- **index.html** — game markup
- **style.css** — layout and appearance
- **script.js** — gameplay and win/draw logic

## Notes
This is a local browser game. No server or database is required.
